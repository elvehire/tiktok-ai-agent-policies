About the application

TikTok-AI-Agent is a Windows desktop application and command-line tool for scanning a local video folder, creating vertical video parts, preparing editable caption drafts, optionally generating subtitles with locally installed Whisper.cpp software and a local model, and—when separately configured, authorized, and consented to—sending a selected video to TikTok through TikTok's official APIs.

Video processing and optional transcription run on the user's computer. TikTok is contacted for authorization and TikTok API functions. Local processing does not itself publish a video.
